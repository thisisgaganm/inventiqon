# Brand assets

The university mark on the foundation page is a text placeholder, not an official logo. When the approved Dayananda Sagar University asset is available, place it in this folder and replace the `.university-mark` placeholder in each page with an `<img>` that uses a relative path and descriptive alt text. Preserve clear space and do not recolor the official mark.

The INVENTIQON wordmark and circuit symbol are provided as the scalable `../inventiqon-logo.svg` asset. Use it with descriptive alt text and preserve its proportions.
